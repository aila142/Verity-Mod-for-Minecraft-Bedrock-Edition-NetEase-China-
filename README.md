# Verity
你的智能伙伴

Verity是为我的世界网易基岩版制作的AI伙伴模组。
在方块世界中，Verity会陪伴你的生存冒险，与你聊天对话，提供生存建议，协助你探索世界。

随着游戏时间推移，它的性格会发生变化，拥有独特的剧情与氛围体验。
和它互动，感受这个特别的智能伙伴带来的不一样的游戏乐趣。
